# Power System Canon v1

Source consolidated from your lore package on 2026-05-07.

## Core System Name
- **The Endless Possibilities and Mysteries**

## Non-Negotiable Principles
- No strongest Path; only strongest user.
- Every Path is individual and identity-shaped.
- Emotions, philosophy, trauma, memory, instinct, and will are power material.
- Mysteries are universal fragments that passively enhance body, soul, mind, Path, and efficiency.

## First Dream Rule
- At age 15, every being faces **Peace** or **Ascent**.
- Peace keeps mortality.
- Ascent starts trial and cultivation progression.

## Universal Progression
- Universal system has **9 Great Circles** (3 minor stages each).
- Current detailed canon provided for:
  - Circle 1: Mortality
  - Circle 2: Adopt
  - Circle 3: Transformation
  - Circle 4: Control
  - Circle 5: Red Dust

## Mystery Marks Canon
- Passive boost scales by thresholds.
- At **1,000 marks**: baseline 2x effect equivalent.
- Scaling increases by each 1,000 marks (2,000 => 3x, etc.).
- 7 mastery stages:
  - Formation
  - Newbie
  - Controller
  - Master
  - Saga
  - Supreme
  - Ultimate
- Controller stage uses **Mystery Bones**:
  - 1 bone = 10,000 marks
  - 206 bones = full canonical set

## Circle-Specific Power Constraints (from lore files)
- Second Circle: six-sense field around 100m, lifespan up to ~500 years.
- Third Circle: embodiment system (0-20, 20-99, 100-200), 10km six-sense attack reach.
- Fourth Circle: 100+ bones requirement for stage entry, 999km six-sense field.
- Fifth Circle: rebirth-based growth and domain-scale control.
